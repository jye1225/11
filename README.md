# 11 포인터 실습

- test01.c: 변수 주소와 포인터 값 비교
- test02.c: 정수 전체와 첫 바이트를 각각 간접 참조 (4, 300으로 비교)
- test03.c: 값 전달과 포인터를 이용한 교환 비교
- test04.c: 점수 5개 입력, 포인터로 출력하고 평균 계산
- test05.c: char, int, double 포인터의 증가 폭 비교

주소와 포인터 크기는 실행 환경에 따라 달라진다. 실습 2에서 300의 첫 바이트가 44인 것은 현재 리틀 엔디언 PC 기준이다.
실습 5는 가상의 주소 10000 대신 실제 배열에서 포인터를 움직인다. 이 PC에서 증가 폭은 1, 4, 8바이트다.

VS Code에서 11 폴더를 열고 실행할 C 파일에 F5를 누른다.
